# Customization Tracker — Odoo Online 19 (SaaS)

A centralized tracking tool for Odoo development teams to record client requirements, custom module efforts, customization requests, developer workloads, auto-versioning history (`V1.0 → V1.1 → V2.0`), client sign-offs, and downloadable module files.

---

## 🚀 Free Hosting on Vercel

This repository is pre-configured with `vercel.json` and `api/index.js` for seamless deployment on **Vercel**.

### Step 1: Commit and Push to GitHub

Run these commands in terminal:

```bash
git add .
git commit -m "Add Vercel serverless configuration and API route"
git push origin main
```

---

### Step 2: Deploy on Vercel

1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **Add New...** → **Project**.
3. Import your GitHub repository (`Development-Tracking-System` / `odoo-customization-tracker`).
4. Framework Preset: **Vite** (automatically detected).
5. Click **Deploy**.

Vercel will build the frontend assets and deploy the backend API serverless functions automatically! Your live link will be ready in under 1 minute.
